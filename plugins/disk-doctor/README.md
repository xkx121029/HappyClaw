# 磁盘体检 (disk-doctor)

只读的磁盘/目录体积检查工具，用来定位"空间去哪了"。**不会删除或改动任何文件。**

## 工具

| 工具 | 参数 | 说明 |
|---|---|---|
| `disk_overview` | `path=""`、`top=10` | 显示所在盘符的总量/已用/可用，并列出该路径下体积最大的直接子目录 |
| `find_large_files` | `path`、`min_mb=100`、`limit=20` | 递归找出大于阈值的文件，按体积倒序 |

## 注意

- 扫描有 5000 条目上限，超限时结果会标注"已截断"，此时数字是**下限**而非精确值。
- 跟随符号链接被禁用，避免绕圈。
- `top` 上限 30，`limit` 上限 50。

安装：`octop plugin install ./plugins/disk-doctor`
