# HappyClaw 1.0.3b5 发布说明

> 面向使用者。版本：`1.0.3b5`，整理时间：2026-11-12。
> 这一版把 HappyClaw 收成了「一台电脑、一个人」的工具：没有账号，打开就能用。

## 一句话概括

去掉了登录、邀请、成员账号和权限配置；数据仍然全部留在本机；升级不会清空 `~/.happyclaw`，并新增了默认带会话的备份、退出守卫、快捷键和数据目录入口。

## 这一版去掉了什么

- **账号与登录**：没有注册、登录页、密码、验证码，也没有「忘记密码」。
- **邀请与成员**：没有邀请码、成员列表、用户分组，不能把工作台分享给另一个登录用户。
- **角色与管理员**：没有角色模板、权限勾选、管理员/成员之分。启动后自动以本机使用者 `local-owner` 运行。
- **JWT 与登录令牌**：接口不再要求 `Authorization`。旧客户端如果还带 token，服务端会忽略它，不会因此报错。
- **第三方登录**：LDAP、OIDC、OAuth、通行密钥、MFA 的入口不再出现在界面上；对应接口只返回「未启用」，不会真的登录。

需要区分一件事：去掉的是**按人组织的团队**（成员账号、邀请、共享给其他登录用户），不是**专家团队**。多个 AI 专家在一个房间里协作的「专家团队」功能完整保留。

## 首次启动是什么体验

1. 安装或解压后启动（桌面端双击图标，或命令行 `octop run`）。
2. 没有登录页，也没有设置向导；浏览器打开 `http://localhost:8088` 直接进入聊天。
3. 服务端在首次启动时自动建库、绑定本地 SQLite，并创建本机使用者 `local-owner`。`/api/setup/status` 会返回 `setup_required: false`。如果 `~/.happyclaw` 不存在（新机器、换路径或目录被清理），启动时会自行创建配置、数据库、日志与备份目录，不需要手工建目录。
4. 桌面端首次打开会有一个两步引导：
   - 第一步说明「这台机器上没有账号」，并给出数据目录位置，可直接打开；
   - 第二步介绍托盘、唤起窗口与新建会话的快捷键，以及「登录时自动启动」开关（默认关闭）。
   - 之后可从菜单「帮助 → 首次引导」重看。
5. 日志在 `~/.happyclaw/logs/octop.log`，按天轮转成 `octop.YYYY-MM-DD.log`。

## 老用户升级会不会丢数据

不会因为升级本身删除数据。升级只替换程序文件，`~/.happyclaw` 原地保留：

- SQLite 数据库、会话与消息、专家与工作区、知识库文件、通道配置、定时任务、模型与插件配置都会保留；
- 启动时会自动完成数据库结构迁移，不需要手动执行脚本；
- 旧的账号、角色、邀请表仍留在数据库里作为兼容数据，但不再参与登录，也不会再出现账号切换；
- 旧书签 `/admin/users`、`/admin/sso` 会自动跳回聊天页；`/login`、`/invite` 已不存在，会落到 404 提示，重新打开根地址即可；
- Docker 部署的数据卷 `/data/.octop` 不变，`HAPPYCLAW_DEFAULT_PASSWORD`、`HAPPYCLAW_ADMIN_USERNAME` 这类旧环境变量不再需要。

两点提醒：

- 如果你之前用多个账号，升级后统一以本机使用者身份进入，**其他账号名下的内容不会自动合并**。升级前先做一次备份，升级后核对常用专家和会话是否都在。
- 升级前建议留一份可搬走的备份：

```bash
octop backup create --include-chats -o D:\backup\before-1.0.3b5.tar.gz
```

## 这一版新增/变化的东西

- **备份默认带会话**：自动备份和托盘菜单里的「立即备份」默认包含聊天历史（`backup.include_chats: true`）。命令行 `octop backup create` 仍是精简备份，需要 `--include-chats` 才打包会话。
- **退出守卫**：有对话或任务正在跑时，从菜单退出会先提示，确认后才结束；关窗口默认只是收进托盘，不会打断正在生成的内容。
- **托盘菜单**：打开窗口、立即备份、退出。备份完成后可直接打开备份文件夹。
- **快捷键**：
  - 工作台：`mod + K` 命令面板、`mod + Shift + O` 新建会话、`mod + Shift + M` 切换模型、`mod + ,` 设置、`mod + B` 导航栏、`mod + Shift + B` 会话栏（`mod` 为 macOS 的 ⌘，其他平台 Ctrl）；
  - 桌面端：唤起窗口、新建会话的全局快捷键以首次引导页显示的为准（帮助 → 首次引导可重看）。
- **数据目录入口**：菜单「帮助 → 打开数据目录」，首次引导页也有「打开」按钮；备份完成提示里可以直接定位到 `~/.happyclaw/backups/`。
- **图形化备份**：设置 → 备份，可以创建、上传归档、从列表恢复，并查看自动备份计划与保留份数。

## 已知边界

- `/api/auth/*`、`/api/users`、`/api/teams` 仍保留兼容响应（例如 `/api/auth/me` 返回 `local-owner`，写操作返回 `400`），方便旧客户端不崩，但不应作为新集成的依据。
- `docs/ldap.md` 和两份旧 HTML 指南是历史资料，已标注失效或快照，请以 `docs/user-guide.md` 为准。
- 部分旧界面文案仍可能出现「管理员」「成员」「用户分组」字样，不影响功能；已列入清理清单，后续版本统一改为本机单人表述。

## 升级建议步骤

1. 停掉正在运行的服务（桌面端从托盘退出）。
2. 执行上面的 `octop backup create --include-chats`。
3. 安装/替换 1.0.3b5，重新启动。
4. 打开 `http://localhost:8088/api/health`，确认返回 `{"ok": true, ...}`。
5. 检查常用专家、最近会话、模型与通道是否正常；有问题按 [单机迁移与恢复](migration-and-restore.md) 回退。
